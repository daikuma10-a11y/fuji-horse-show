# Winterの事前エントリー一括登録（2026-10-11）

大会本部の「出番表 → 事前エントリーを出番表に登録」で、馬の所属クラブを選び、所属馬を選択して馬単位の入力欄を追加する。その馬の下に競技・騎乗選手の行を入力し、「この馬の出場を追加」で複数の競技・騎乗選手を登録する。別の馬も同じ一覧へ追加できる。馬名・所属を見出しとしてまとめ、各行で馬を繰り返し選択しない。確認一覧も馬ごとにまとめる。選手は既存の所属・参加チェック検証に従い選択団体の参加選手から選ぶ。未入力の空行は除外し、一部だけ入力された行は確認時に拒否する。

非公認の出場区分は通常／OPを各行で指定（OP料金未設定競技は通常のみ）。指導者競技会などの会員料金競技は各行で会員／非会員を指定。指導者資格確認、日馬連登録、公認OP禁止、Winter大会ID、所属、参加チェックの既存検証を維持。

確認一覧に各人馬・競技・区分・競技料と合計を表示。追加手数料0、入金済みにせず、厩舎料等は別。確認後に既存の認証付き・冪等なregister_winter_initial_entryを順次実行。各行の登録番号を維持し、登録済みの行は再送しない。途中で不確定になった行は同じ番号と内容で再確認する。全件が同時に成功するトランザクションではなく、登録済み／未確認と件数を表示する。登録の途中では画面を更新せず、この一覧から続きを操作する。

同一団体限定、同じ競技・選手・馬の一覧内重複を保存前に拒否。既存の出番表にある人馬も確認時とサーバー側で拒否。サーバー関数・DBスキーマ・Autumnは変更しない。

検査：型検査、Nextビルド、40競技の料金・資格・大会隔離・冪等性の既存テスト、一括テスト（通常/OP、指導者会員/非会員、重複事前拒否、途中失敗から同じ番号で再開、登録済み再送防止）。テストは通信モックで行い、実人馬や出番の書込みはしていない。実機画面の確認はユーザー側で行う。
