# 締切前の取込・精算準備

`/winter/prepare` で、名簿・正式出番・事前精算の資料を独立して確認する。ブラウザ内の処理のみで、DBへの保存・受付申請・支払確定を行わない。入力を閉じる前に準備JSONをダウンロードし、同じ大会IDのファイルだけ再開できる。

## 資料の準備

- CSV UTF-8又はExcelからの表貼付。見出しは画面の雛形順に揃える。
- 名簿は団体／選手／馬。識別番号は大会内で種別ごとに一意。Excel側で文字列にし、先頭0を保存する。
- 乗馬協会の会員区分（第5・25）と指導者協会の会員区分（第8・32）を分ける。指導者資格は別項目。空欄を会員にしない。
- 出番は競技番号、1からの連番、選手・馬の識別番号、明示的OP。非公認と公認のJEF確認要件を分ける。馬のグレード申請の有無は原本で別途確認する。
- 事前請求は各団体の申込原本総額（馬匹登録料等を含む）と確認済み入金額。変更後の出番から再計算せず独立して保持する。過入金・原本未確認は確定扱いにしない。

## 締切後に接続する部分

記入済み申込書の形式を確認し、必要な列対応を設定する。既存DBとの同一性・競合検査、管理者権限の原子的一括取込、実データを使った端末確認はまだ接続していない。ダウンロードJSONは取込命令ではない。受領・精算の保存、支払方法の確定、領収書と再印刷も別途接続が必要。
