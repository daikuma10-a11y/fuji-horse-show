# Winter取込接続・復旧版（2026-10-20）

## 対象と由来
基準はGitHub保存済み8b62ced。会話中の実際のapply_patch／ファイル生成コードを再利用し、失われた取込接続だけを復旧した。d3d5380のGit原本・原本hashを取得できず、同一コードとは主張しない。
- 再利用：登録照合／安定ID／逐次保存、確認UI、CSV/TSV画面への接続、既存料金台帳読取、ダミー自動テストの実コード。
- 再実装：記録文書の組立て、短縮した対象DB検査、保存後の確認一覧再表示、別所属の自動検査。前回と同じ仕様範囲。
- 既存共通マスター、名簿管理・Winter参加チェック、料金計算、事前登録RPCを再利用。DB構造・権限・保存単位・公開先は変更しない。
- .xlsx/PDF直接取込、Web申込一本化、実参加資料投入、入金処理、Autumn本番は対象外。

## 対応形式と項目
直接対応は `/winter/prepare` で保存できる3つのCSV UTF-8／TSV雛形（Excelからタブ区切り貼付可）。列名・列順は固定。識別番号は文字列として先頭ゼロを維持。

| 資料 | 項目 | 対応 |
| --- | --- | --- |
| 名簿 | 種別・識別番号・団体番号 | 団体／選手／馬の原本参照キー。既存の所属別IDを明示選択 |
| 名簿 | 名前・日馬連番号 | 既存登録との一致確認。不一致は差分表示し停止 |
| 名簿 | ふりがな | 原本確認用表示。既存名簿を自動変更しない |
| 名簿 | 日馬連確認・騎乗者資格 | 既存の公認資格審査。馬のグレード申請は別途原本で確認 |
| 名簿 | 乗馬協会会員 | 第5・25競技の会員／非会員区分 |
| 名簿 | 指導者協会会員・指導者資格確認 | 第8・32競技の料金区分と資格 |
| 出番 | 競技番号・選手番号・馬番号・OP | 対応済みの既存Winter競技／人馬／参加区分 |
| 出番 | 出番 | 原本内の連番・重複確認。既存出番順は上書きせず末尾追加 |
| 事前精算 | 団体番号・事前申込合計・入金額・原本確認 | 原本総額と確認済み入金額を独立保持。DB入金へ転記しない |

原本総額には馬匹登録料等が含まれるので競技料金小計との単純一致を要求しない。全団体の原本会計確認が完了するまで確定不可。推測補完・氏名だけの自動統合はしない。

## 操作
1. 既存Winter大会本部でログイン→「締切前の準備を確認」。
2. 3雛形を読込、形式エラーを修正しWinter原本のチェックを付ける。読込だけでDBには書かない。
3. 原本を一意に識別する資料番号を入力→参加名簿・登録履歴を読む。未登録人馬は「既存の人馬名簿を開く」で従来の追加・参加チェック保存を行い、読み直す。結果不明の新規名簿保存は先に再読込し、二重に新規保存しない。
4. 団体・選手・馬を所属とともに明示選択→照合・確認一覧。差分は確認／修正まで停止。他所属選手・馬は既存処理どおり選手所属に請求し、一覧に表示する。
5. 原本・資格・区分・料金・所属を確認してチェック→管理者確定。既存RPCへ1件ずつ保存。登録後は再読込結果を一覧表示。
6. 停止時は処理中1件の結果確認後に止まる。終了／停止後は再開JSONを保存。再開は端末記録／JSON→原本チェック→照合→確定。確認済みの登録はスキップする。
7. 仮出番表と精算明細は既存本部画面で確認。正式順序は従来の出番表操作で調整。

## 再開・訂正の制約
- Winter ID＋同一資料番号＋原本行位置から安定UUIDを生成。再取込／訂正版／端末移行でも資料番号を変更しない。
- 送信前に端末へ「結果不明」を記録し、DB読戻し後に「登録確認済み」。端末記録保存失敗なら送信停止。未登録・結果不明・登録済みを区別。
- 再開JSONの完了表示を信用せずDB台帳・現在出番と照合。結果不明は同じUUIDで再送。APIは同内容なら同ID、違う内容なら拒否。
- 同じ資料番号の原本・対応変更は停止し、原本差分を表示。既存の変更／棄権履歴や料金差分も停止。既存人馬・出番・料金を上書き／削除しない。
- 同一競技・同一人馬の2回目OPも既存事前APIが非対応のため停止。
- 訂正は既存の変更・棄権・精算手順で確認する。行追加／削除／並べ替えの自動マージは未対応。番号を変えて訂正版を新規登録しない。
- 原本総額／確認済み入金額は端末記録と再開JSONに保持。原本台帳のDB新設はしない。端末移行前にJSONを保存する。資料を失い番号・競技・人馬まで変更した申込の同一性は自動判定不能。
- 再開資料には個人情報が入り得る。公開GitHubへ置かない。開発用退避bundleには実申込資料・ブラウザー記録・認証情報を含めない。
