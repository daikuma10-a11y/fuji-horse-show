# 出番編成の人馬識別・タイムテーブル印刷（2026-11-05）

## 依頼と範囲

- 同じ競技に複数回出る選手・馬だけを個別に色分け。出番の並べ替えを補助する。
- 一旦停止したタイムテーブル作業は利用者の「タイムテーブルの作業も続けてください」で再開。
- 添付 `25winterタイムテーブル.xlsx` の障害／馬場を左右に置く構成を参考に、今年の管理画面から印刷する。
- 基点 `prep/winter-2026` の `3445718e409eda10c76091c0f76b04cfd2fc747b`。実参加データ・出番順・時間・料金・入金はこの開発では変更しない。

## 使える機能

### 人馬の色分け

共通 `MasterStartRows` の管理用表示に実装。選手名と馬名をそれぞれ色付けし、「選1×2」「馬1×2」のようにグループと出場回数を併記。所属が違う同一人馬は既存の共通名簿のID対応を再利用する。名前だけで同一とみなさない。

競技をまたがず、棄権を除き、OPは含める。並べ替え・表示上の団体絞り込みで色と番号は変わらない。別人馬が追加・削除された場合や共通IDの照合前後には割当が変わる場合がある。8色を超えるグループも番号で区別できる。追加／変更の行色、近接出番の注意表示、ドラッグ・上下ボタン・保存・競合防止は維持する。

共通名簿の照合中／失敗の表示を、管理出番表の見える位置へ移動。未照合時は各登録IDの範囲で識別する。公開モニター・正式印刷・CSVには編成用の色を追加していない。Autumn/Winter両アダプターの共通描画一致を確認し、Autumn本番は配備しない。

### タイムテーブル

既存の時間編集と `save_winter_timetable` を維持し、全日程／各日付の「印刷・PDF保存」を追加。共通印刷文書・既存の印刷ウィンドウ処理を使用する。Winterアダプターが現在の競技設定・保存済み時間を供給する。

- A4横、障害（第1競技場）と馬場（第2競技場）を左右に表示。日付ごとに改ページ。
- 今年の大会名・日付・競技番号・種目・公認・出場数・下見／開始・予定／確定・作成日時を表示。
- 印刷ボタンで最新データを読み直す。取得失敗では古い内容へフォールバックせず止める。
- 出場数は棄権を除く出番件数（OPを含む）。異なる選手が同じ馬に乗る場合も別の出場として計上。
- 未設定は「未定」。昨年の時刻・会場名・競技固有の注意書きを推測で転記しない。
- 編集途中の時間は先に「時間を保存」。全日程または日付の印刷ボタンからプリンター／PDFを選ぶ。
