# タイムテーブルの日程選択・1ページ印刷（2026-11-05）

追記：利用者PCの印刷プレビューでは2ページになることが報告された。本記録のPDF確認だけでは実機での1ページ出力を証明できていなかった。縮小・改ページ処理を再修正した内容と残る実機確認は [印刷ページ分割への対応](winter-timetable-pagination-20261105.md) を参照。

## 依頼と範囲

利用者指定は「選んだ日程分を1ページ」。土曜・日曜を選べば2日分、全日程を選べば3日分すべてをA4横1ページに収める。以前の「1日ごとに1ページ」という解釈を置き換える。

基点は `prep/winter-2026` の `99c757ba5f91503e1bf8f97ebec54bbacab55dee`。既存の共通マスターとWinterアダプターを修正する。実参加データ・出番順・保存済み時間・料金・入金・DB構造・権限は変更しない。

## 実装

- タイムテーブル上部に日程のチェック欄を追加。初期値は全日程。「全日程を選択」で戻せる。
- 「選択した日程を1ページで印刷・PDF保存」は、選択した日数と1ページにまとめることを表示する。未選択では印刷できない。既存の日付単独ボタンも維持する。
- 印刷開始時に選択日程を固定し、取得中は操作を無効にする。最新の保存済みデータを再取得する既存処理と、通信失敗時に止める動作を維持する。
- 大会名・作成日時・注記を共通にし、障害と馬場を左右に置く。各表の中に日付見出しを付け、選択日程だけを日付順に並べる。競技・人数・下見・開始・公認・確定表示を省略しない。「確定」以外は予定である旨を共通の注記に明示する。
- フォント読み込み後、印刷直前、再印刷時に文書全体の実寸を測り、1枚の印刷領域へ縮小する。競技行や脚注を切り落としてページを減らさない。印刷用紙内の全要素を検証したうえで、縮小前の余分な領域から白紙ページが発生しないようにした。
- 既存の時間編集・保存、出番編成の人馬の色分け、認証、他の印刷処理は維持する。印刷前に編集内容を保存する案内を表示する。
