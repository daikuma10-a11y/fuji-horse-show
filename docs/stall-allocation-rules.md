# FHS 厩舎割 共通ルール

川口大輔さん指定。2026年10月30日版。大会共通で使用。

## 元の配置図

正式資料：25Winter厩舎割(1).xlsx（2025年資料）。「マスター」を基に作り、「25winter」を配置例として参照する。先に送付された26springのファイルは使用しない。

原本：https://chatgpt.com/library?file_id=libfile_48314182ea6881919befd221f69e4709&account_id=personal

S、1〜10番厩舎が使用可能。通常は1番から順番に埋める。マスターの棟位置、馬房番号、TR区画、周辺設備の位置を維持する。団体の図形は原本の形を利用・複製して配置する。

## タックルーム（TR）

TRは道具・馬の餌の保管場所。各団体に原則1つ以上を割り当てる。

|大会の総頭数|団体の頭数|必要TR数|
|---|---|---|
|1〜100頭|1〜3頭|1|
|1〜100頭|4〜7頭|2|
|1〜100頭|8〜10頭|3|
|1〜100頭|11〜13頭|4|
|1〜100頭|14〜16頭|5|
|101〜150頭|1〜4頭|1|
|101〜150頭|5〜8頭|2|
|101〜150頭|9〜12頭|3|
|101〜150頭|13〜16頭|4|
|151〜200頭|1〜5頭|1|
|151〜200頭|6〜10頭|2|
|151〜200頭|11〜15頭|3|
|151〜200頭|16頭以上|4|

150頭は101〜150頭の区分として扱う（原指示の「150〜200」と重なる境界の運用整理）。200頭超、150頭以下の大会で17頭以上参加する団体は未指定なので、必要TR数を個別に設定する。

## 仮設テント

151頭以上の場合は1〜10番厩舎の外に各1張設置し、1張をTR2つ分として扱う。厩舎ごとの共有容量であり、各団体に重複計上しない。アプリの初期運用では通常厩舎の各団体に屋内TRを最低1つ確保し、残りの必要数にテントを充てる。

## ワイヤーのあるTR区画

通常厩舎のマスターでTRとなっている区画には建物を支えるワイヤーがあり、馬が噛む危険がある。原則TRとして優先使用する。空けることは可能。自動配置では馬を入れず、例外的な馬の配置はその区画ごとに管理者が確認して手動で行う。

原本では1〜10番厩舎は番号付き馬房18室と番号のないTR区画2室、S厩舎は番号付き馬房24室。

## S厩舎

広い通路と多い馬房を持つ特別仕様。フジファームに優先利用権がある。なるべく少頭数の団体を配置し、通路に荷物を置いて馬房を節約する。有事にはTRなしで使える。

アプリでは優先団体を登録団体のIDで指定する。少頭数の初期目安は3頭以下とし、画面で変更可能。Sの通路利用は団体単位で選択し、その団体の全頭がSにいる場合に限りTR省略を認める。Sの追加条件は後から追記する。

## 作成・修正の手順

申込締切後、全団体の読み込みが完了した段階で作成する。「締切を過ぎ、全団体の取込が完了した」確認後に「厩舎割を作成」ボタンを押し、登録済み団体・参加馬のIDと頭数を元に配置案を作る。締切前に自動確定しない。

作成後も団体・馬・TR・テントの配置を修正できる。未配置、重複、TR不足、ワイヤー区画の例外を明示し、未配置を隠さない。登録名簿や精算を変更せず、厩舎割だけを保存する。保存は大会別とし、別端末で更新されていた場合は上書きを止める。各大会の団体名・頭数は現在の登録データで入れ替え、昨年の割り当ては参考資料として保持する。
