# 人馬名簿の管理

本部ログイン後にWinter管理画面の「人馬名簿」で、団体選択、選手・馬の参加チェック、個別登録、読みの登録、所属変更を行う。

## 保存モデル

- `fhs_roster_entities` は継続利用する選手・馬の内部ID。日馬連未登録でも登録可能。同名だけでは自動統合しない。同一種類の登録番号重複は止める。
- `fhs_roster_clubs` と `fhs_roster_affiliations` は複数の現在所属と終了した所属。通常保存は所属を追加し他所属も保持。明示的に「他の所属を終了」を選んだときだけ他所属を終了する。
- `fhs_winter_participants` はWinter大会ID・人馬ID・団体IDをキーにした参加記録。同じ人馬を複数団体で登録可能。氏名、読み、番号、所属をチェック保存時に固定する。マスターを編集しても既存参加記録は更新しない。
- 管理画面の削除は `archived_at` による論理削除。選択候補から除外するが所属履歴と保存済み大会記録は消さない。
- 参加チェック保存は団体単位で一括トランザクション。別の操作による変更は元の参加ID一覧と比較して検出する。名簿編集は更新時刻で競合を検出する。
- 全表は管理者のみ。匿名閲覧・書込なし。RLSは編集可能なuser_metadataではなく既存のapp_metadata.roleを使用。
